# Design decisions

Every place the build differs from, or adds to, the provided screens. Kind: **derived** (the design is silent or shows only one state, so the value is derived from the system) or **journey-fix** (the design as drawn would break a journey, accessibility or correctness; the fix is the smallest change that works). Provided screen specs are never edited.
